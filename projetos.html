01 — App Desktop

Marie Curie

Função: transformar PDFs em resumos estruturados e enviá-los ao Obsidian, com apoio de IA generativa.

Marie Curie é uma aplicação desktop em Python, com interface em CustomTkinter. O usuário seleciona um documento em PDF; o software extrai o conteúdo, pede à IA um resumo organizado e grava o resultado em notas no Obsidian.

Serve para quem precisa sair do arquivo bruto e chegar a um texto reutilizável — títulos, blocos e síntese prontos para consulta — sem copiar e colar página a página.

  • Python
  • CustomTkinter
  • IA generativa
  • Obsidian

02 — Web

Sites e interfaces

Função: criar páginas web claras, responsivas e com boa leitura — a presença digital de um produto, serviço ou profissional.

Trabalho com HTML, CSS e TypeScript para montar layout, tipografia, navegação e estados de interface. O objetivo é uma página que se entenda rápido no celular e no desktop, com contraste, hierarquia e chamadas de ação visíveis.

Este portfólio é um exemplo concreto: landing com seções definidas, formulário validado e uma página própria para detalhar projetos.

  • HTML
  • CSS
  • TypeScript

03 — Automação

Automação de fluxos

Função: gerar documentos e processar dados em lote, para reduzir retrabalho manual e manter o resultado consistente.

Scripts em Python que leem entradas, aplicam regras e produzem arquivos prontos — planos, listas, avaliações ou bases tratadas. Em vez de repetir o mesmo passo em dezenas de itens, o software executa o fluxo uma vez e entrega o conjunto.

Serve a rotinas em que o padrão é conhecido e o volume cansa: menos tempo formatando, mais tempo revisando o que realmente importa.

  • Python
  • Automação
  • Processamento de dados
