01 — Sobre

Perfil

O front-end é desenvolvido em HTML, CSS, JavaScript e TypeScript: markup semântico, layout responsivo, tipografia e estados de interface no DOM. Landing page, site institucional ou aplicação web compartilham a mesma base — estrutura clara, CSS previsível e TypeScript onde a lógica exige tipagem.

Os formulários são validados no cliente (campos, e-mail e extensão da mensagem) antes de qualquer envio. A persistência de dados, quando necessária, é feita com SQL. O versionamento ocorre no Git, com histórico e branches.

Fora do navegador, o stack é Python. Aplicação desktop com CustomTkinter, leitura de PDF, chamada a API de modelo generativo e gravação de notas no Obsidian — fluxo implementado no Marie Curie. Scripts geram documentos em lote, processam CSV/JSON e encadeiam etapas de um pipeline enxuto, sem framework desnecessário quando um módulo resolve.

APIs REST são integradas quando o produto depende de serviço externo (IA, webhook ou banco de dados). A escolha da ferramenta segue o problema: TypeScript na interface, Python na automação e no desktop, SQL na consulta. O critério é funcionamento, manutenibilidade e o mínimo de dependências.

  • Front HTML, CSS, JS, TypeScript
  • Desktop e script Python, CustomTkinter
  • Dados e versionamento SQL, Git, API REST
